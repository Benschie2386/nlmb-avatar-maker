# NLMB Avatar Maker

Offline-first Roblox-inspired avatar creator for GitHub Pages.

Features:
- Avatar preview
- Body, hair, face, clothing, accessories, back items and effects categories
- Glowing eyes with multiple colors and intensity
- Aura, wings, crown and mask toggles
- Random avatar
- Local outfit saving
- PWA / service worker
- No Roblox login
- No backend
